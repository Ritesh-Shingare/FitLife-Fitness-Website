# FitLife - Fitness & Wellness

A beginner-friendly multi-page fitness and wellness website built using HTML and CSS.

## About the Project

FitLife is a simple fitness and wellness website created as a frontend development pratice project.
It provides information about fitness activities and includes different course sections such as gym, yoga, cardio, strength training, and meditation.

## Features

- Multi-page website
- Navigation between pages
- Fitness and wellness information
- Embedded workout videos
- Course section
- contact form
- Hover effects

## Technologies Used

- HTML 5
- CSS3
- Git
- GitHub

## Pages

- **Home** - Introdroduction to FitLife
- **About** - Information about fitness and wellness activities
- **Courses** Fitness and meditation video courses
- **Contact** - Contact form for users
